# Portfolio — Siaci Abdennour

Site personnel présentant mon parcours de développeur Java en évolution vers un profil fullstack (Java, SQL, React).

🔗 **Site en ligne :** [abdesci.github.io](https://abdesci.github.io/)

## Pages

- `index.html` — Accueil, présentation, CV
- `experiences.html` — Expérience professionnelle
- `formations.html` — Parcours de formation
- `competences.html` — Compétences techniques
- `projets.html` — Projets personnels
- `contact.html` — Coordonnées et disponibilité

## Stack

HTML5 / CSS3 / JavaScript vanilla — site statique hébergé sur GitHub Pages, sans dépendance ni build.

- `style.css` — feuille de style unique et responsive partagée par toutes les pages
- `script.js` — menu mobile, effet de scroll sur la navigation, repli sur les initiales si la photo de profil est absente

## Lancer en local

Aucune installation nécessaire : ouvrir `index.html` dans un navigateur, ou servir le dossier avec :

```bash
python3 -m http.server 8000
```

puis ouvrir `http://localhost:8000`.
